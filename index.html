Projects

I've worked on some neat things.
IT Communications Drafting Agent

I built an AI-powered Copilot agent that drafts consistent IT communications, including emails, announcements, service updates, and incident notifications. The agent analyzes user-provided content and adapts tone, urgency, and messaging style for different audiences and situations. I integrated web-grounded search capabilities to supplement missing information and enhance the accuracy, clarity, and completeness of communications. By automating message creation and refinement, the solution improved communication efficiency and reduced the manual effort required from IT staff.

Replit Slot Machine Game

I developed a browser-based slot machine game using HTML, CSS, and JavaScript, implementing the core game logic, random outcome generation, and interactive user experience. I utilized JavaScript for DOM manipulation, event handling, and dynamic updates to display spinning reels, track results, and manage gameplay states. I designed and styled the interface with CSS to create an engaging and responsive user experience. This project strengthened my front-end development skills by combining programming logic, user interface design, and real-time interaction within a fully functional web application.

Book Library Site

I developed a web-based library management application for Temple University's CIS 3309 course that enabled users to securely log in and manage library resources. I implemented functionality for viewing the library catalog, borrowing and returning books, and tracking book availability in real time. The system also monitored loan records and identified overdue books, providing users with visibility into borrowed and outstanding materials. Through this project, I gained experience designing database-driven applications, implementing user authentication, managing data relationships, and creating intuitive interfaces for library operations.
